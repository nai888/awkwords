# Awkwords

Awkwords is a simple online application that randomly generates words from a given pattern. Awkwords was created by [Petr Mejzlík](https://github.com/petmir) sometime in the late 2000s, and version 1.2 was released in 2010.

Versions 1.0 through 1.2 were built using PHP. The new version 1.3 is completely rebuilt from scratch using Vue 3 and Vite. This allows the app to work without PHP, or truly without a server at all. It also can now run blazingly fast, and works just as well on your phone.
